# BeautyGuard：懂美妆内容生态的 AI 鉴真 Agent

**赛题**：欧莱雅美妆科技黑客松 · 赛题2「信任守护师 —— 创造者的 AI 卫士」

---

## 1. 问题与机会

美妆是种草内容最密集的品类之一，也是造假最集中的品类之一。消费者在决策时依赖的“真实体验”正被四类内容侵蚀：

| 场景 | 典型造假 | 对谁造成伤害 |
|---|---|---|
| 种草图片 | 前后对比图局部磨皮/美白夸大功效；粘贴“专柜正品/官方认证”贴纸；复制产品伪造“满柜现货” | 消费者被误导；品牌被冒用 |
| AI 生成素材 | AI 生成的“完美皮肤”效果图、产品大片冒充实拍，且未标识 | 消费者预期失真；真实创作者被劣币驱逐 |
| 种草文案 | AI 批量生成的“伪真人测评”；“7 天美白”“根除色斑”等违规功效宣称；“原单尾单 1:1”假货暗语；软广不标广告 | 违反广告法与化妆品监督管理条例 |
| 评论区 | 模板化好评、集中爆发刷评、批量注册水军账号、好评返现 | 口碑信号失真，违反反不正当竞争法 |

现有方案的局限：通用 AIGC 检测器只回答“是否 AI 生成”，**不懂美妆语境**（例如“美白”属于特殊化妆品功效宣称、前后对比图是功效夸大的重灾区）；黑盒分类器只给分数**不给依据**，审核员无法据此处置，创作者也无从申诉。

**我们的目标**：打造一个懂美妆内容生态、**可解释**、能**从识别走到决策**的内容核验 Agent。

## 2. 方案总览

```
美妆笔记(图+文+评论)
      │
  ① 感知与规划 Planner ── 识别模态，动态生成工具调用计划
      │
  ② 工具层 ───────────────────────────────────────────────
  │  图像取证：ELA / 噪声一致性 / 复制-移动 / 元数据 / 频域纹理
  │  Qwen-VL：语义级视觉研判 ──► ③ 自适应深挖：可疑区域裁剪放大复核
  │  文案：违规宣称词库 × 法规知识库 / AI 文案统计特征 / Qwen 语义研判
  │  评论：近重复聚类 / 时间爆发 / 账号画像
  │  跨模态：图文一致性核验
  ─────────────────────────────────────────────────────────
      │
  ④ 证据融合：维度内置信度加权 Noisy-OR，维度间加权 → 可信分
      │
  ⑤ 风险决策：四级分级 × 策略库 → 平台 / 创作者 / 消费者三方建议 + 法规依据
      │
  ⑥ 大模型复核 + 可解释报告（Markdown/JSON，含完整 Agent 轨迹）
```

设计原则：
1. **传统取证 + 大模型互补**：取证算法给出像素级、可复现的物理证据（“这里的噪声断层”），大模型给出语义级判断（“瓶身文字畸形”“光影方向不一致”）。取证结果作为提示交给大模型，大模型复核又能压低算法误报。
2. **每一个结论都有依据**：每条证据包含 `异常分数 × 方法置信度 × 自然语言说明 × 定位（区域/文本片段）× 法规条款`。
3. **可降级**：未接入大模型时，纯本地取证仍可完成全流程闭环，适合隐私敏感场景与离线批处理。
4. **全部基于开源模型**（赛题技术要求）：TruFor（深度篡改定位）、RapidOCR（截图识别）、可选的 Qwen2.5-VL / Qwen2.5（开源权重，DashScope 调用或本地 vLLM 部署），不依赖任何闭源模型。

## 3. 多模态检测方法

### 3.1 图像取证

| 检测器 | 原理 | 美妆场景 | 误报控制 |
|---|---|---|---|
| ELA 误差水平分析 | 以 Q90 重压缩，比较各块压缩误差 | 粘贴的认证贴纸、替换的产品/批号 | **纹理回归去内容化**（ELA 随边缘增强，只看残差）；屏蔽强边缘块（叠加文字）与图像边界 |
| 传感器噪声一致性 | 中值滤波残差的分块标准差 + 鲁棒 z 分数 | **前后对比图的局部磨皮/美白**、跨来源拼接 | 排除饱和/过暗块；全图近乎无噪声时交由 AIGC 检测器处理 |
| 复制-移动 | SIFT 自匹配 → 位移向量聚类 → RANSAC 校验纯平移 | 复制产品伪造“满柜现货”、遮盖瑕疵 | **前后对比图两次拍摄存在旋转缩放不判为复制**；重复文字（“使用前/后”）构成的细长区域不计 |
| **TruFor 深度篡改定位**（开源，CVPR 2023） | RGB 语义 + Noiseprint++ 相机指纹的 Transformer 融合，输出像素级篡改图、整图完整性分数、可靠性图 | 拼接贴纸、局部修补、磨皮、AI 局部编辑；**对平台重压缩鲁棒** | 只取高可靠性区域；低于 0.45 的分数视为无证据（实测真实照片缩放后最高约 0.45） |
| 元数据取证 | EXIF、PNG 文本块、C2PA、AIGC 隐式标识 | 美图/PS 导出痕迹；SD/ComfyUI 生成参数 | 无 EXIF 仅作弱线索（平台会剥离） |
| 频域 + 纹理统计 | FFT 高频周期峰、全图噪声水平、生成模型典型分辨率 | AI 生成的“完美皮肤”与产品大片 | 多线索累加，单一线索不定罪 |
| Qwen-VL 研判 | 视觉大模型结合取证提示做语义审查 | 畸形文字/Logo、光影/透视错误、试色色差、伪造检测报告 | 区域放大复核，对算法可疑区二次确认 |

### 3.2 文案检测

- **违规宣称词库 × 法规知识库**：覆盖极限用语、医疗化宣称、时限效果承诺、无依据数据与背书、误导性成分宣称、假货暗语、站外导流、好评返现等 10 余类，每类绑定法规条款（《广告法》第九/十七/二十八条、《化妆品监督管理条例》第二十二/三十七/四十三条、《化妆品功效宣称评价规范》、《互联网广告管理办法》第九条、《反不正当竞争法》第八条、《人工智能生成合成内容标识办法》等）。
- **开源词库合并**：并入 china-compliance-skills（MIT）的 200+ 广告法违禁词，按美妆场景筛选，新增“诱导消费”“贬低竞品”两类，每个命中附**合规替换建议**（如“最好 → 优秀/出色/值得推荐”）。
- **上下文豁免与否定语境**：“第一次用”“最大的缺点是贵”“治愈系包装”“不敢说最好”等合法表述自动排除，并在报告中列出排除理由，降低真实测评被误伤。
- **未标注广告识别**：带货信号（价格、链接、直播间）存在而无“广告/合作”标识。
- **AI 文案统计特征**：句长变异系数（burstiness）、大模型套话密度、第一人称具体细节密度（肤质、用量、价格、缺点）、emoji 模板化排版、结构化行文。真人测评的典型特征是“有缺点、有细节、长短不一”。
- **Qwen 语义研判**：识别词库覆盖不到的隐晦夸大与伪真人测评。

### 3.3 评论区检测

- 字符 2–4 gram TF-IDF 余弦相似度聚类 → 雷同评论簇；
- 空泛模板好评（夸赞词多、细节为零）、返现/导流话术；
- 10 分钟滑窗时间爆发检测（相对期望频率倍数）；
- 账号画像：新注册、零粉零内容、系统默认/批量昵称。
- **评论区层面同质化**：单条“好用，回购了”可能是真人，但同一评论区内大量空泛好评即为刷评信号。这一特征在缺少账号/时间信息（如截图、导出文本）时尤其关键。

### 3.4 小红书截图入口

小红书开放平台仅提供电商接口，不开放笔记/评论读取；爬取违反平台协议且涉及他人个人信息。因此我们支持**直接上传笔记截图**：
1. 按“非背景像素行占比”自动定位并裁出配图（不依赖 OCR，配图内含文字也不受影响）；
2. 开源 RapidOCR（本地）或 Qwen-VL（接入 Key 时）提取标题、正文、评论，并把“10-01 河南 回复”这类元信息解析为评论时间；
3. 提取结果可在界面上人工修正后再核验；
4. Agent 识别截图来源后，对 ELA/噪声/TruFor 等像素级证据**自动降权一半**（屏幕渲染与重编码会破坏这些痕迹），文案与评论检测不受影响；
5. 支持多张截图合并（正文页 + 评论续页）；作者本人的评论回复不计入水军分析，而是并入文案做宣称检测（作者常在置顶评论里补充带货话术）。

**真实笔记示例**（出于隐私考虑，真实截图未随公开仓库发布）：一篇淡斑精华种草笔记的正文页 + 评论页。
系统判定为**高风险（可信分 26），建议限流 + 人工复核**，依据：“淡斑力比普通烟酰胺快了近两倍”（无来源的倍数比较数据）、“脸即刻亮了一度两度”（即时功效宣称）、
“+7啵啵间”（以谐音指代直播间、带货未标注广告）、“美白/淡斑”（特殊功效需核验特证）。这一真实样本还暴露并推动修正了 4 处问题：低分辨率截图的配图定位、
重复词叠加导致过度处置、倍数/即时功效类宣称漏检、谐音规避词漏检；并据此引入“比例原则”——仅文案宣称存疑且无医疗化/假货等严重类别时，最高判为“高风险→人工复核”，不自动下架。
*该结论为系统风险提示，不构成对具体品牌或博主的违规认定。*

## 4. Agent 设计：从识别到决策

| 阶段 | 说明 |
|---|---|
| 感知与规划 | 识别输入模态与可用能力，动态生成执行计划（有图才取证，有图有文才做一致性核验，接入大模型才调用语义研判） |
| 工具调用 | 每步记录 `思考 → 动作 → 观察 → 耗时`，单个工具失败不影响闭环 |
| 自适应深挖 | 取证发现可疑区域 → 自动裁剪放大 → Qwen-VL 复核，确认或推翻算法结论 |
| 证据融合 | 维度内 `1 − Π(1 − score × confidence)`：多路证据互证则风险上升，单一弱证据被抑制；维度间加权得综合风险，可信分 = 100 × (1 − 风险) |
| 风险决策 | 低（<0.25 放行抽检）/ 中（打标 + 抽样复核）/ 高（限流 + P1 人工复核 + 风险提示）/ 极高（下架 + 证据固化 + 48h 申诉通道）；按命中维度追加专项动作（强制 AI 标识、违规词屏蔽 + 合规专员核验特证、折叠水军评论、转品牌打假等） |
| 三方建议 | **平台**处置动作、**创作者**整改指引（保护善意创作者，给出合规改法而非一刀切）、**消费者**风险提示 |
| 报告 | 结论、可信分、维度雷达、可疑区域热力图、文案高亮、水军评论表、法规依据、完整轨迹，可导出 Markdown/JSON |

## 5. 数据集与实验

### 5.1 演示数据集（`data/`）

18 条带真值标签的美妆笔记（图 + 文 + 评论），17 张图片：
- 真实实拍 4 张、真实前后对比 2 张（两次拍摄，含角度/光线差异）；
- 拼接 3 张（粘贴来自不同压缩历史的“专柜正品”贴纸/他牌产品）；
- 复制-移动 3 张（复制产品伪造现货）；
- 磨皮夸大前后对比 2 张（局部双边滤波 + 提亮，美图/PS 导出元数据）；
- AI 生成风格 3 张（无传感器噪声、2× 上采样网格伪影、典型生成分辨率，其中 2 张含 SD 生成参数）。
- 文案 8 类：真实测评 ×2、AI 伪测评 ×2、违规功效 ×2、假货暗语、未标广告；评论：真实评论 / 水军评论（模板 + 爆发 + 新号）。

> 图片为程序化合成，用于完整演示闭环；阈值在该集上标定。

### 5.2 闭环评测结果（本地取证模式，`python -m eval.run_eval`）

| 指标 | 数值 |
|---|---|
| 样本数 | 18（真实 5 / 伪造或违规 13） |
| 准确率 / 精确率 / 召回率 / F1 | 100% / 100% / 100% / 100% |
| 分维度（篡改 / AI 未标识 / 违规宣称 / 刷评） | 召回 8/8、3/3、6/6、5/5，精确率均 100% |

### 5.3 泛化与鲁棒性（`python -m eval.robustness`）

用**未参与标定的新随机种子**生成留出集（每类 6 张），并模拟平台二次处理。消融对比“仅传统取证”与“传统取证 + TruFor”：

| 类型 | 原图 | 平台重压缩 Q75 | 缩放 0.75 + Q85 |
|---|---|---|---|
| 真实实拍（判为真实） | 1.00 → 1.00 | 1.00 → 1.00 | 1.00 → 1.00 |
| 真实前后对比拼图（判为真实） | 0.83 → 0.83 | 1.00 → 1.00 | 1.00 → **0.17** |
| 复制-移动 | 1.00 → 1.00 | 1.00 → 1.00 | 1.00 → 1.00 |
| 磨皮夸大 | 1.00 → 1.00 | 1.00 → 1.00 | 1.00 → 1.00 |
| AI 生成 | 1.00 → 1.00 | 1.00 → 1.00 | 1.00 → 1.00 |
| 拼接 | 0.50 → **1.00** | 0.00 → **1.00** | 0.33 → **1.00** |
| **整体** | 0.889 → **0.972** | 0.833 → **1.000** | 0.889 → 0.861 |

（箭头左侧为仅传统取证，右侧为 + TruFor）

**结论与诚实说明**：
- 接入开源 TruFor 后，**拼接检测从 0–50% 提升到 100%，且不受平台重压缩/缩放影响**，补上了 ELA 的最大短板；真实实拍照片无新增误报。
- 新引入的局限：**经过缩放的真实前后对比拼图**会被 TruFor 判为合成（两张照片拼在一起本身就是合成版式，缩放后更明显）。在美妆场景中前后对比图本身就是高风险内容，进入“人工复核”是可接受的保守策略，但这仍是误报，后续计划做拼图版式识别后逐面板检测。
- 复制-移动由 SIFT 自匹配负责（TruFor 对同图复制不敏感），二者互补。

### 5.4 评论区检测：真实小红书评论验证（`python -m eval.comment_realworld`）

数据：RedBookletReview（MIT）约 1.08 万条真实小红书评论。该数据集原始标注为情感，**不是水军标注**，因此设计两组实验：随机抽取 200 个评论区（每区 30 条），
实验 1 全部为真实评论，衡量误报；实验 2 注入刷评，衡量检出。注入刷评有两种写法：A 为模板拼接（用于调参），B 为手写留出（**不参与任何调参**，检验过拟合）。
数据集无昵称/时间/账号信息，以下结果**仅依赖文本特征**。

| 实验 | 评论级精确率 | 评论级召回率 | 评论区告警率 |
|---|---|---|---|
| 1. 纯真实评论区（6000 条） | — | 误判 **0 条（0%）** | **0%** |
| 2A 模板刷评 3/30 · 6/30 · 10/30 | 99.7% · 99.7% · 99.9% | 56.5% · 74.5% · 74.8% | 0% · 51.5% · 98.5% |
| 2B 留出刷评 3/30 · 6/30 · 10/30 | 99.8% · 99.9% · 99.95% | 91.0% · 94.0% · 95.4% | 0% · 96.0% · 100% |

**过程说明**：首次在真实数据上验证时，刷评召回仅约 **30%**，暴露出原检测器依赖“逐字雷同”与账号/时间信息、对改写过的刷评不敏感的问题（演示集上的 100% 掩盖了这一点）。
我们据此新增“评论区层面同质化好评”特征并重新校准评论区风险分，召回提升到 57–95%，同时真实评论**零误报**。

**局限**：该数据集话题以泛生活为主，美妆评论区中真实好评的比例更高，实际误报率可能高于 0%；少量刷评（3/30）时评论区整体不告警，仅逐条标记。

## 6. 业务价值

- **平台**：自动分级分流，高风险内容 P1 复核，低风险放行，降低人工审核量；处置附证据快照与法规依据，可直接用于工单与申诉。
- **品牌（欧莱雅）**：监测冒用品牌、假货暗语与虚假功效宣称，保护品牌资产；对达人合作内容做发布前合规预检。
- **创作者**：发布前自检，给出具体整改建议（补 AI 标识、改违规词、提供原图），保护真实创作者不被 AI 批量内容与水军稀释。
- **消费者**：在内容页获得“AI 生成”“功效未经核实”“评论区疑似刷评”等可理解的提示。

## 7. 局限与路线图

| 当前局限 | 计划 |
|---|---|
| 缩放后的前后对比拼图被 TruFor 误判 | 拼图版式识别 + 逐面板检测；结合 Qwen-VL 判断是否为正常拼图 |
| TruFor 许可仅限非营利用途 | 商业化时替换为商用许可模型或获取授权 |
| 本地 AIGC 图像检测基于统计线索 | 接入 GenImage 上训练的检测器；读取 C2PA / AIGC 隐式标识做强证据 |
